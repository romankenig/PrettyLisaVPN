# Размер Windows-клиента

Отдельная задача упаковки: Windows 0.19.0 → 0.19.1, PATCH. Backend 0.24.0,
Android 0.16.0 и engine API 0.4.0 не меняются.

Предыдущий опубликованный EXE 0.18.1: 71 531 520 байт, merge SHA
`63c429b7125b74c4b0ce30d0deafb562c18b826e`, Windows run 41070412774/1.

Дистрибутив собирается через Cargo release с opt-level=s, thin LTO и одной
codegen unit; panic unwinding сохраняется. Go-движок собирается с -s -w и
сжимается GZip внутри единственного EXE. Это упаковка файла, не новый протокол
и не изменение зависимостей движка. Wintun остаётся неизменённым подписанным DLL.
Существующий elevated helper раскрывает движок в созданный для сеанса каталог
с прежними ACL и удаляет после остановки. GZip CRC/размер проверяются при чтении,
выход ограничен 64 MiB; повреждённый или неподходящий файл не запускается.

Используется уже присутствующая в Cargo.lock permissive-библиотека flate2.
Исходники и уведомления продолжают поставляться отдельными файлами на дашборде.
UI review по-прежнему использует текущую debug-сборку для диагностических
снимков; реальная opt-in приёмка запускает именно release EXE дистрибутива.

Проверки: восстановление встроенного PE, отказ при повреждении CRC/усечении,
не-PE и превышении лимита; native tests/clippy; реальная приёмка на CI.
Окончательные байты, product/build SHA/run/attempt и результаты публикации
фиксируются в PR после сборки; этот документ не заявляет завершённую выкладку.
