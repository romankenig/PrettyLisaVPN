# Способы подключения и автоматический выбор

Источник перечня: [статья Habr 799751](https://habr.com/ru/articles/799751/).
Это перечень упоминаний, а не обещание устойчивости к блокировкам.

| Семейства | Упомянутые варианты |
| --- | --- |
| Классические VPN | OpenVPN TCP/UDP; IPsec; WireGuard; AmneziaWG; SSTP; SoftEther; AnyConnect/OpenConnect, camouflage |
| Зашифрованные прокси | Shadowsocks, Shadowsocks-2022, UoT; VMess; VLESS; Trojan; SSH; Hysteria, Hysteria2, Salamander |
| Транспорты и маскировка | TLS; uTLS; XTLS-Vision; REALITY; XUDP; WebSocket; gRPC; HTTP/2; HTTPUpgrade; SplitTunnel; mKCP; QUIC; SRTP/DTLS/uTP; Cloak; ShadowTLS |
| Специальные варианты | SOCKS; HTTP Custom; Tor, bridges, Snowflake, WebTunnel; PingTunnel; DNSTT, DNSTT+SSH |
| Схемы развёртывания | CDN; REALITY со своим сайтом; дополнительный выход через WARP |

Outline — реализация Shadowsocks. Xray/V2Ray/V2Fly/sing-box — движки;
панели и названия клиентских приложений не создают новых протоколов.

## Решения владельца от 2026-10-23

- Автоматический выбор ограничен зашифрованными подключениями через DE/US.
  Незашифрованные SOCKS/HTTP и выходы Tor/WARP не входят в цепочку.
- Движки устанавливаются отдельно и управляются PrettyLisaVPN. Последнее
  решение отменяет промежуточный выбор встроенных движков.
- sing-box исключён по решению владельца. Новый компонент использует Xray
  (MPL-2.0), собственный адаптер — MIT; допустимы разрешительные зависимости
  MIT/BSD/Apache/ISC. GPL/AGPL-библиотеки в него не добавляются. Непубликованный
  прототип sing-box заменён до commit/push.
- На Android отдельное приложение-служба должно владеть VPN-разрешением и
  всеми переключениями; основной APK управляет им через защищённый IPC.
- Один запрос подключения сохраняет выбранную страну и серверную авторизацию.
  Неудачная попытка не создаёт новую платную/бесплатную сессию.
- Каждая попытка ограничена по времени. После ошибки туннель останавливается;
  неподтверждённая остановка прекращает перебор. Отмена, выход из аккаунта,
  отзыв устройства и истечение доступа имеют приоритет над следующей попыткой.
- Windows отсчитывает остаток от получения ответа сервера по монотонным часам;
  попытки и проверки не добавляют время к сессии. После отмены серверная
  авторизация сохраняется до подтверждённой остановки локального туннеля.
- Подключение подтверждается проверкой DNS и HTTPS через собственный туннель.
  Только после этого UI показывает фактический способ. Handshake недостаточен.
- В цепочку попадают только реально развёрнутые и авторизованные конфигурации,
  для которых установлен совместимый движок. Каталог не является доказательством
  работающего транспорта; результаты испытаний фиксируются отдельно.
