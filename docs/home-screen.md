# Домашний экран Windows — 0.3.0

## Выбор подключения

Источник доступности — существующий GET /vpn/countries. В выпадающем списке три
группы: автопилот; до трёх доступных стран по убыванию quality; все available=true
страны по русскому алфавиту. При равном рейтинге порядок алфавитный. Рейтинг —
серверный quality от 0 до 100, не измеренная клиентом скорость или ping.

Строка содержит локальный круглый SVG-флаг, русское название и рейтинг; у
автопилота — глобус. Circle Flags включён в приложение с MIT-лицензией, без
загрузки картинок во время работы. Список поддерживает мышь, стрелки, Home/End,
Enter/Space, Escape и поиск по начальной букве. Переполнение прокручивается
внутри списка, окно остаётся 960 × 640.

Выбор хранится отдельно для аккаунта в localStorage под
prettylisavpn.location.<user-id>; только mode/country_code. При первом запуске,
повреждённой/недоступной storage или недоступной выбранной стране — автопилот.
Список обновляется раз в минуту и вручную; при ошибке старые рейтинги не разрешают
новое подключение. Во время подключения/активного туннеля выбор заблокирован.
Кнопка и подтверждённый VPN orchestration status находятся под выбором; справа
оставлена пустая панель. Connected по-прежнему требует проверки интернета.

## Аккаунт и тариф

PREMIUM отображается со ⭐, PLATINUM — с 💎, FREE — без символа. Клиент принимает
PLATINUM в /me и auth-ответах, но backend этой задачи не вводит новый тариф,
платёжные правила или права. Backend в исходниках остаётся 0.1.0.

«Статус: активен» пока сохранён как прежняя статичная подпись авторизованного
аккаунта. В /me нет account status; эта подпись не является состоянием VPN или
подписки. Удаление/замена этой подписи — по решению владельца.

## Текущая локация

Внизу левой панели показаны фактически наблюдаемые город, страна и внешний IP.
Источник — отдельный PublicLocationProvider; основной backend не меняется.
Default: GET https://ipwho.is/, настройка VITE_PUBLIC_LOCATION_URL позволяет
заменить endpoint на совместимый ответ: success=true, ip, country_code, city.
Приватные аккаунтные токены и cookies провайдеру не передаются; результат не
сохраняется и не логируется. Геолокация относится к IP, а не к GPS/почтовому адресу.

Обновление: при открытии экрана, раз в 60 секунд после завершения запроса,
при focus/online и после смены состояния сети/VPN. Timeout запроса — 8 секунд.
Во время переходных фаз старый адрес скрыт; запросы прежней сети отменяются,
поздние ответы игнорируются. После ошибки показано «не удалось определить»
и повторная попытка; ошибка не меняет VPN status и не блокирует отключение.

Страна выбранного сервера не подставляется вместо наблюдения. При split routing,
другом VPN/прокси или ошибке маршрутизации может отображаться другая страна — это
фактический результат запроса, а не доказательство исправного VPN. Если сервис
не возвращает город/страну, показаны «город неизвестен»/«страна неизвестна».

UI review использует отдельный loopback fixture /public-location с документальным
IP 203.0.113.42. HTTP endpoint разрешён только в test-окружении. Fixture не
подтверждает доступность реального провайдера или production VPN; проверить это
на реальном Windows-клиенте при отключённом и включённом VPN остаётся отдельным
пунктом проверки интеграции. Провайдер и его ограничения заменяемы адаптером.
