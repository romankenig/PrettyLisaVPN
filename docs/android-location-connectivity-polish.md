## Поведение

- Home: один dropdown с автопилотом, тремя лучшими и всеми доступными странами.
  Топ отсортирован по quality убыванию с локализованным именем при равенстве;
  все страны — по локализованному имени. Доступность/quality 0–100 поступают из
  GET /vpn/countries, в том числе autopilot. Некорректные значения отвергаются;
  неизвестный рейтинг обозначается тире, без вымышленных измерений.
- Флаги ISO отображает системный Android emoji-шрифт, как в выборе языка;
  автопилот/неизвестная страна — глобус. Windows использует SVG-спрайт;
  смысл и рейтинг одинаковы, внешний вид флагов зависит от Android.
- Текущие публичные регион/IP компактно под кнопкой в карточке подключения.
  Public metadata lookup отделён от auth, ничего не отправляет о пользователе.
  Нет отдельной карточки текущей сети; Connect остаётся только UI preview.
- Devices: ACTIVE only, current first, яркая крупная отметка. Отзыв скрывает
  конкретный UUID после подтверждения сервера; ошибки оставляют устройство.
  Совпадение имени не склеивает разные установки. Серверная история не удаляется.
- Settings → «уведомления сервиса»: уведомления о подписке/аккаунте, а не чат
  поддержки. Пояснение переведено на шесть языков; ACK/revision guards сохранены.
- Исправлены начала предложений, включая logout/error/dialog/fixture тексты.
  Checker теперь проверяет и следующие предложения. Имена, бренды, протоколы,
  пользовательские значения и серверное содержимое не преобразуются в runtime.
- Над нижней полосой версий на всех live-маршрутах показывается предупреждение
  «нет связи с сервером, проверьте подключение к интернету». Android следит за
  validated default network, включая captive portals/смену сети; public /version
  проверяется сразу и каждые 15 секунд при STARTED Activity, timeout 5 секунд,
  без redirect/retry/auth/cookies. Геолокация не определяет доступность backend.
  Потеря сети отменяет опрос; восстановление перепроверяет сервер и скрывает
  полосу. В фоне callback/опрос освобождаются. Не выполняются фоновые mutations.

сверка diff с remote HEAD. Android SDK/эмулятора в workspace нет: Gradle JVM,

без OTP-писем, отправки поддержки, реальных платежей или VPN-туннеля.

скриншоты фиксируются в описании PR #25 после CI, без docs-only повторного push.

отдельные задачи. Новые автоматические привязки/списания не добавлены.
