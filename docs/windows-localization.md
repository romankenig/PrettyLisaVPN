# Windows: языки интерфейса

Windows **0.11.1 → 0.12.0**: новый выбор языка; backend **0.10.0** и Android
не меняются. Основные исходники — `apps/windows/src/i18n`, компонент
`LanguageSelector`, наблюдатель `HomeCountryObserver`.

Внизу левой панели доступен combobox с SVG-флагом, английским и родным названием.
Порядок фиксирован по английским именам: Chinese / 中文 (CN), English / English
(GB), French / Français (FR), German / Deutsch (DE), Russian / Русский (RU),
Spanish / Español (ES). Китайский — упрощённый. Флаги используют существующий
лицензированный sprite; emoji-флаги, которые Windows отображает буквами, не нужны.

Первый запуск/offline — английский. При подтверждённом выключенном туннеле
локация RU выбирает русский, другие/неизвестные страны — английский. До входа
разрешён только read-only probe локального туннеля: DOWN должен подтвердиться
до и после запроса локации; изменение состояния/abort отменяет результат.
Поднятый/неизвестный туннель не используется для определения исходной страны.
Нет нового геосервиса, координат или истории IP; используется существующий provider.

Ручной выбор сохраняется отдельным ключом `prettylisavpn:language` и имеет
приоритет над геолокацией, VPN-выходом, ОС и последующими ответами. При отказе
localStorage выбор работает в памяти. Язык применяется без перезапуска/потери
форм, сессии и VPN-состояния; обновляются также уже показанные ошибки, aria/title,
даты, цены и названия стран. `html.lang` отражает выбранный язык. Меню поддерживает
стрелки, Home/End, Enter/Space, Escape, Tab, закрытие снаружи и возврат фокуса.

Каталог содержит 257 UI-сообщений на шести языках с одинаковыми параметрами.
Исходные русские строки служат стабильными ключами; перевод применяется на границе
рендера, а не к состояниям/кодам API или DOM после React. Это сохраняет динамическую
смену языка для ранее возникших ошибок и не меняет бизнес-логику.
`PrettyLisaVPN` и существующие английские подписи (CONNECT, Connected, Free,
WireGuard, DNS, frontend/backend и т. п.) сохраняются. Email, имена устройств,
ключи/адреса, ввод пользователя, подписи платёжного провайдера и авторский контент
сообщений аккаунта не переводятся машинно. В messages API передаётся язык приложения;
многоязычная публикация авторских сообщений остаётся задачей автора/контента.

Проверки: preference persistence/failure/priority, полнота каталогов и параметров,
клавиатура/фокус/click-away, перевод уже показанной ошибки без потери ввода,
ограничение геолокации при VPN/race; существующие регрессии UI.
Windows UI review собирает текущий commit, проходит прежние сценарии и снимает
реальные native окна для всех шести языков, раскрытого меню, английской поддержки
и восстановления языка после reload. API/аккаунт/туннель в этом прогоне — fixtures,
не реальные письма, списания или VPN-трафик. Точные SHA/run/attempt, статусы всех CI
и PNG фиксируются в task PR после завершения проверок.
