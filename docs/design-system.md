# Визуальный стиль PrettyLisaVPN

Эта палитра является канонической для новых интерфейсов PrettyLisaVPN. Названия и HEX
взяты из утверждённого цветового референса. Компоненты должны использовать семантические
токены своей платформы, сохраняя эти исходные значения.

| Цвет         | HEX       | Основная роль                                           |
| ------------ | --------- | ------------------------------------------------------- |
| Black        | `#010101` | Логотип, основной текст на светлом фоне                 |
| Mercury      | `#e4e4e4` | Светлый фон и разделители                               |
| Purple Heart | `#5f22d9` | Основной брендовый цвет, действия и крупные поверхности |
| Christalle   | `#2c016d` | Тёмный брендовый фон и состояния навигации              |
| Dusty Gray   | `#9c9c9c` | Вторичный текст                                         |
| Galliano     | `#d7ad0d` | Предупреждение или небольшой акцент                     |
| Scorpion     | `#5b5b5b` | Основной нейтральный текст                              |
| Viking       | `#51d6ca` | Контрастный акцент и активное состояние                 |
| Heliotrope   | `#ac73ff` | Мягкий фиолетовый акцент и focus-ring                   |
| Persian Red  | `#c82b28` | Ошибка и опасное действие                               |

Purple Heart и Christalle формируют основные брендовые поверхности. Viking применяется
точечно, чтобы активные элементы оставались заметными. Galliano и Persian Red не должны
использоваться как декоративные цвета: их смысл — предупреждение и ошибка. Проверяйте
контраст текста для каждой новой комбинации, особенно для Dusty Gray и Heliotrope.

Полный логотип состоит из замка-сердца и надписи PrettyLisaVPN. На главных экранах
используется SVG целиком. Для иконки приложения и малых квадратных областей используется
только знак замка из того же SVG, без надписи и без самостоятельной перерисовки.

По уточнению владельца иконки выбранных сервисов на главной используют цвета
самих сервисов: размер 20 px/dp, промежуток 4 px/dp, одна строка с многоточием
при переполнении. В окне выбора сохраняется палитра PrettyLisaVPN.
Сервисы и сайты без логотипа не получают заглушку на главной: вместо них
показывается многоточие, даже если в строке осталось место.

## Написание названия

Название продукта всегда пишется `PrettyLisaVPN`, включая интерфейс и сообщения
об ошибках. Общий строчный стиль подписей не меняет регистр названия; для него
используется `.product-name` с `text-transform: none`.
