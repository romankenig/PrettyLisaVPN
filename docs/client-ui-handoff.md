## Проверенная исходная структура

Windows: `apps/windows`, Tauri 2 + Rust + React 19 + TypeScript + Vite.
Версия package/config: `0.1.0`. Окно Tauri: 960 × 640, минимум 720 × 480.
В `src-tauri/tauri.conf.json` сейчас `bundle.active: false`.

Экраны по `apps/windows/src/ui/App.tsx`:

1. `/login` — вход по email.
2. `/auth/verify-otp` — ввод OTP.
3. `/` — аккаунт, выбор локации и управление VPN.
4. `/devices` — устройства.
5. `/about` — версия и окружение.

Есть отдельный SessionRestorationGate. Главная отображает состояния подключения, проверки интернета, ошибки и оставшееся время Free-сессии. Полный перечень визуальных состояний ещё нужно проверить запуском.

Общие визуальные правила: `docs/design-system.md`.
Другие платформы представлены каталогами, наличие готовых клиентов не подтверждено.
